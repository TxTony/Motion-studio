# MS-002 — Revision Animation: view-independent contracts and playback

Status **In review**. Owner **`animation_domain`** (`gpt-6.2-sol`, `medium` effort), with the lead agent as coordinator. Depends on MS-001. See the [architecture](../ARCHITECTURE.md), [studio data model](../../src/domain/studio.ts), and [animation tests](../../tests/animation.test.ts).

JSON v1 clips, recording, and playback run in the domain independently of Vue, the DOM, and Three.js. The injected Three.js interpolator preserves the existing values. The migration preserves the format, duration, sampling, and rounding.

Acceptance criteria include preserving the characterization tests, demonstrating RED/GREEN for interpolation injection, validating unknown JSON data, checking dependency boundaries, and documenting function intent.

## Implementation

- Rig, capture, and clip contracts live in `src/domain/studio.ts`. Recording, playback, and serialization live in `src/domain/animation/`.
- `AnimationPlayer` requires a `PoseInterpolator`. The adapter in `src/infrastructure/three/interpolateRigPose.ts` preserves root lerp and slerp for each local rotation.
- `AnimationSerializer.parse(json: string)` treats the result of `JSON.parse` as `unknown`. Its guards retained the bounds, tolerances, and JSON v1 errors at the time of the migration. The prototype's `Blob` export declaration had no consumers and stays outside the domain.
