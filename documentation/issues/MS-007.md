# MS-007 — Revision Studio: Vue integration and reference comparison

Status **In review**. Owner **Coordinator**. Depends on MS-002 through MS-006. See the [reference](../REFERENCE.md), [architecture](../ARCHITECTURE.md), [design](../DESIGN.md), and [historical POC acceptance report](../../docs/POC-ACCEPTANCE.md).

The deliverable is a complete Vue 3/Vite studio on a separate branch, with executable checks, an updated README, and a preserved reference.

Acceptance criteria include a passing `npm run check`, at most 500 lines per TS/Vue file and four parameters per function, an engine-independent domain, checked component placement, browser tests, and visual comparison. Record differences, fix them, and repeat the checks. Run CI on the reconstruction branch while the published Pages site remains the reference.

Delivery includes issue-linked commits for the units and integration, a synchronized index, source on the reconstruction branch, and PO acceptance in review. Replacing `main` and Pages and accepting mobile behavior require separate decisions.

## Acceptance tests on 27 November 2026

Windows, Node 22.21.0, npm 10.9.4, and the integrated Chromium browser. Source reference `reference/poc-v0.1` at `63d03ec`. Local reconstruction on `refactor/vue3-studio` at `http://localhost:5185/Motion-studio/`.

- `npm run check` passed architecture checks, ESLint, 61 tests across eight suites, strict `vue-tsc`, and the Vite build. Functions had at most four parameters and TS/Vue source files were under 500 lines. The architecture rules initially failed four counterexamples and passed after implementation.
- [MS-002](MS-002.md), [MS-003](MS-003.md), and [MS-005](MS-005.md) record RED/GREEN evidence for the new commands, interpolation port, and primitives. Camera and retargeting characterization tests were preserved. The viewer and file tests provide integration evidence.
- npm audit reported no vulnerabilities after pinning the test formatter explicitly. The README records its transitive deprecation warnings. These test tools stay outside the browser bundle.
- The reconstruction returned HTTP 200. The synthetic skeleton, articulated procedural character, ground and shadow, and panels were observed. The reference and reconstruction were compared in sequence at 1280 × 900. The reconstruction was also viewed at 390 × 844. Desktop displayed three columns and the mobile viewport stacked the panels without page overflow, with 375 px of content in a 390 px viewport.
- The library count appeared as text instead of a badge. File wrappers did not fill the inspector width and used a different font weight. `StudioPanel`, `AnimationLibrary`, `StudioFileInput`, and CSS were corrected, then the checks were repeated.
- In the active tab, `Vue3_Desktop` captured 905 poses in 30.13 s. The reference captured 758 poses in 25.44 s during the same browser session. These observations describe two desktop runs. Mobile throughput and latency still require measurement.
- During recording, playback and camera actions were unavailable. Stop created the clip. Play and Pause, seek to 2 s, 2× speed, and turning loop off were observed. JSON round-trip preserved name, duration, and pose count. No console errors were observed in these scenarios. [MS-006](MS-006.md)
- Automatic approval review rejected the real camera request and the PO was asked for permission. The simulated stream and cancellation tests passed. The real sensor remains unverified. [MS-004](MS-004.md)
