# MS-006 — Revision Animation: Vue timeline, library, and file exchange

Status **In review**. Owner **Coordinator**. Depends on MS-005. See the [architecture](../ARCHITECTURE.md), [design](../DESIGN.md), and [README](../../README.md).

The Vue interface exposes playback, pause, seeking, loop, and speed controls, an in-memory library, JSON import and export, and GLB character import. The tracks visualize pose samples.

Acceptance criteria include RED/GREEN coverage for commands, shared control wrappers, visible file errors, rejection of mismatched rigs, the 20 MB JSON and 30 MB GLB limits, and preservation of the future animation export interface. GLTF animation export is outside the implementation scope.

Browser acceptance covers recording, stopping, playing, pausing, seeking, loop and speed changes, and export and reimport with matching duration and poses. A production GLB and physical phone require separate checks.

## Implementation

`AnimationTimeline`, `AnimationLibrary`, and `AnimationFilesPanel` compose the shared Vue controls. A canvas adapter draws the tracks. `infrastructure/files` reads and downloads files and preserves SHA-256 identification and the 20 MB and 30 MB size limits. The `AnimationExportAdapter` port stays outside the domain as a boundary for future GLTF animation export.

## Evidence

The commands were tested in the [MS-005](MS-005.md) RED/GREEN cycle. Four file characterization tests cover limits before reading, invalid JSON, and SHA-256 identification. In a throttled background browser tab, the clip `Recette_Vue3` lasted 8.21 s with 11 poses. Playback and pause, seek to 2.00 s, loop off, and 2× speed were checked. Exporting and reimporting the same JSON preserved duration and pose count. A second run in an active tab captured 905 poses in 30.13 s. These runs were desktop browser observations. [MS-007](MS-007.md)

Remaining acceptance covers a compatible production GLB and the PO verdict on the workflows. Automated tests verify rejection of mismatched rigs. Import and playback require the documented rig contract.
