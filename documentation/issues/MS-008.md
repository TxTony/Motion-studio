# MS-008 — Revision Studio: English language and character-independent identity

Status: In review. Owner: coordinator. Contributors: animation_domain (gpt-6.2-sol, medium), design_reference (inherited model), english_documentation (gpt-6.2-sol, medium). Authorization: PO request on 27 November 2026 to use English throughout source, UI, tests and documentation, and keep product/engine naming independent of the sample character.

Scope: active working tree on refactor/vue3-studio. Rename the sample-character factory and visible identity to neutral terms. Translate comments, test descriptions, messages, configuration labels and documentation. Preserve geometry, behavior, JSON v1 and the archived reference tag/worktree/image. Mascot creation is explicitly deferred.

Compatibility decision: new clips use `default-character-v1`. Import compatibility with the previous default rig is handled at the file boundary by a SHA-256 identifier fingerprint, without carrying a character-specific identifier into the current source or docs. The importer maps that recognized identifier to the current default-rig identifier; it does not accept arbitrary mismatched rigs. Add a RED/GREEN test for this migration and retain rejection of unrelated rigs. Do not alter the general serializer or custom GLB identifiers.

Acceptance: all maintained first-party text is English; current source/docs have neutral character terminology; existing automated checks pass; browser UI/record/playback/import checked; old default-rig JSON remains reusable. Immutable Git history and reference imagery are not rewritten. Record precise checks and remaining camera/device limitations.
